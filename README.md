# BioScan_Robot
The follwoing GitHub library holds all the documentation on the BioScan Robot which includes the python scripts, schematics, models and produced instruction manuals.

ADVISORY: the ASL machine learning code forgot to get uploaded to the GitHub, but once the Raspberry pi 5 attached to the touchscreen is booted up the ASL machine learning code will load when vs code is opened.

Each of the .py files are for the robot to function where launcher.py enables each of the functinos to run in parallel. There should be some physical PCBs printed out already, but if further modifications are made then the design and schematic is in this repository.

The radar and thermal camera run on the Raspberry pi 3. However, that pi might be misplaced so the software and packages will most likely need to be installed on a newer pi like the 5.
